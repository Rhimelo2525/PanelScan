# PanelScan Representative Image Assets

These WebP files are original representative visualizations used where approved product or installation photography is not yet available. They are not photographs of actual Disenyo Interior Solution products or completed projects.

## Assets

- `home/hero-fluted-interior.webp` — representative interior with fluted wall panelling in a wood-look finish
- `categories/wall-panels.webp` — representative installed fluted wall panelling in a wood-look finish
- `categories/ceiling-panels.webp` — representative white PVC ceiling-panel interior
- `interiors/panel-installation.webp` — representative panel-installation process

The imagery is limited to PanelScan's current PVC wall-panel and ceiling-panel presentation. Product images supplied by the API take priority over these category assets.

## Production asset guidance

Replace representative imagery with approved photographs of the client's own panels and completed installations when available. Preserve the existing aspect ratios and WebP optimization so page layout and loading performance remain stable.
